| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Arsitektur | Aplikasi berjalan di browser dengan pola client-server; antarmuka dirender di sisi klien dan data umumnya disediakan oleh server melalui API. | Aplikasi dipasang dan berjalan di sistem operasi komputer; dapat menggunakan layanan lokal maupun terhubung ke server. | Aplikasi berjalan di perangkat seluler, secara native atau melalui runtime lintas platform, dan dapat mengakses fitur perangkat. |
| Bahasa utama | HTML, CSS, dan JavaScript/TypeScript. | Java, C#, C++, atau Python, bergantung pada sistem operasi dan framework. | Kotlin atau Java untuk Android, Swift untuk iOS, serta Dart atau JavaScript untuk solusi lintas platform. |
| Distribusi | Di-host pada server dan diakses melalui URL menggunakan browser. | Dipaketkan sebagai installer atau aplikasi melalui toko aplikasi desktop. | Dipublikasikan melalui toko aplikasi seperti Google Play atau Apple App Store, atau didistribusikan melalui kanal lain yang didukung. |
| Keunggulan | Mudah diakses lintas perangkat tanpa instalasi; pembaruan dapat dilakukan terpusat di server. | Dapat memanfaatkan sumber daya komputer dan integrasi sistem operasi; dapat mendukung penggunaan offline. | Memanfaatkan kamera, GPS, sensor, dan notifikasi; mudah dibawa dan digunakan saat bepergian. |
| Keterbatasan | Bergantung pada browser dan koneksi untuk fitur atau data tertentu; akses ke fitur perangkat dibatasi oleh browser. | Instalasi dan pemeliharaan dapat berbeda antar sistem operasi; distribusi pembaruan perlu dikelola. | Perlu mempertimbangkan variasi perangkat dan versi sistem operasi; distribusi serta persetujuan toko aplikasi dapat membatasi rilis. |
| Contoh aplikasi | Google Docs, Wikipedia, dan layanan web perbankan. | LibreOffice, Visual Studio Code, dan aplikasi desktop perbankan. | WhatsApp, Google Maps, dan aplikasi mobile perbankan. |
